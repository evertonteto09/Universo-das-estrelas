🔒 Política de Privacidade:

Última atualização: 23 de julho de 2026

Bem-vindo!

A privacidade dos usuários é importante para a equipe do Universo das Estrelas.

Esta política explica quais informações são utilizadas pelos nossos bots, por que elas são necessárias e como elas são tratadas durante o funcionamento dos serviços.

Nosso objetivo é coletar apenas os dados estritamente necessários para o funcionamento das funcionalidades oferecidas.

1. Dados armazenados

Armazenamos apenas informações fornecidas voluntariamente pelos próprios usuários para utilização em sistemas dos bots, como por exemplo:

  • Informações do comando Sobre Mim;
  • Nomes de personagens em sistemas de RP ou RPG;
  • Configurações personalizadas;
  • Preferências necessárias para determinadas funcionalidades.

Não coletamos informações além daquelas necessárias para o funcionamento desses sistemas.

2. Identificação dos usuários

Para garantir que cada informação pertença ao usuário correto, utilizamos o identificador oficial do Discord (User ID).

Esse identificador é utilizado apenas para vincular dados às respectivas contas e permitir o funcionamento adequado dos recursos oferecidos pelos bots.

3. Mensagens e comandos

Os bots não armazenam permanentemente mensagens enviadas pelos usuários nem os comandos utilizados durante o uso normal.

Após o processamento do comando, as informações necessárias para sua execução são descartadas imediatamente, salvo quando o próprio comando possuir a finalidade de salvar dados fornecidos voluntariamente pelo usuário.

4. Cuide das suas informações

Nunca envie informações pessoais sensíveis através dos bots.

Evite informar dados como:

  • CPF;
  • RG;
  • Passaporte;
  • Endereço residencial;
  • Telefone;
  • E-mail pessoal;
  • IP de internet;
  • Senhas;
  • Dados bancários.

Quando necessário, utilize apenas informações simples, como seu primeiro nome e sobrenome.

5. Solicitação de dados

Atualmente ainda não disponibilizamos uma ferramenta para que o usuário visualize ou solicite a remoção dos dados armazenados.

Entretanto, pretendemos implementar esse recurso futuramente para oferecer maior transparência e controle sobre as informações cadastradas.

6. Segurança das informações

Empregamos boas práticas para proteger os dados armazenados pelos bots.

Apesar disso, nenhum sistema conectado à internet pode garantir segurança absoluta, motivo pelo qual recomendamos que os usuários evitem compartilhar informações sensíveis.

7. Compartilhamento de dados

O Universo das Estrelas não vende, aluga ou compartilha os dados armazenados com terceiros para fins comerciais.

As informações somente poderão ser utilizadas pela equipe responsável pela manutenção dos bots ou quando houver obrigação legal.

8. Alterações desta Política

Esta Política de Privacidade poderá ser atualizada sempre que novas funcionalidades forem adicionadas aos bots ou quando houver mudanças na forma de tratamento das informações.

9. Sistema de Mensagens Anônimas

O comando de mensagens anônimas foi desenvolvido exclusivamente para permitir o envio de mensagens sem revelar a identidade do remetente ao destinatário.

Embora a identidade não seja exibida ao usuário que recebe a mensagem, a equipe do Universo das Estrelas poderá registrar ou identificar o autor da mensagem quando necessário, especialmente em casos de denúncias, abuso do sistema, assédio, ameaças, divulgação de conteúdo ilegal ou qualquer violação dos Termos de Uso.

O uso do anonimato não concede permissão para praticar ofensas, perseguições, intimidações ou qualquer outra conduta inadequada. Usuários que utilizarem esse recurso de forma abusiva poderão sofrer punições, incluindo a suspensão permanente do acesso aos bots e, quando cabível, a comunicação às autoridades competentes.

O sistema foi criado para facilitar o envio de mensagens respeitosas quando o usuário prefere não revelar sua identidade.

Utilize esse recurso com responsabilidade e bom senso. O envio de mensagens ofensivas, discriminatórias, ameaçadoras, enganosas ou que tenham como objetivo prejudicar terceiros poderá resultar na perda permanente do acesso ao sistema.

Os dados deste comando poderão ficar salvos em até 7 dias em nosso banco de dados. as vitímas devem realizar a denúncia até o fim deste período.

ATENÇÃO!

A identidade do remetente permanece oculta apenas para o destinatário da mensagem. Caso o recurso de denúncia seja utilizado e for identificada alguma violação dos Termos de Uso, a equipe poderá consultar o registro do envio para realizar a análise do caso e aplicar as medidas cabíveis.

10. Aceitação da Política

Ao utilizar qualquer bot pertencente ao Universo das Estrelas, você declara estar ciente desta Política de Privacidade e concorda com o tratamento das informações descrito neste documento.

Perguntas Frequentes:

O que coletemos?

Apenas informações fornecidas pelo próprio Discord.

Como:

  • User ID
  • Nome de usuário
  • Avatares e banners.

Coletamos conteúdos disponibilizados pelos próprios usuários voluntariamente por nossos comandos de salvamento.

O que não coletamos?

Não salvamos mensagens enviadas nos servidores e grupos privados.

Não registramos comandos após sua execução (exceto quando o objetivo do comando é salvar informações).

Todos os dados vindos do discord são automaticamente apagadas ao término da execução do comando.
